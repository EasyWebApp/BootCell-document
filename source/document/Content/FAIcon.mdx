import { FAIcon, FABGIcon } from 'boot-cell';

import { Example } from '../../component/Example';

BootCell requires Font Awesome Free v7. Load the v7 stylesheet once; do not
load the previous v5 or v6 styles alongside it.

```html
<link
    rel="stylesheet"
    href="https://unpkg.com/@fortawesome/fontawesome-free@7.3.1/css/all.min.css"
/>
```

`FAIcon` defaults to `family="classic"` and `group="solid"`. Brand icons use
`group="brands"`:

<Example>
    <FAIcon name="camera" />
    <FAIcon name="github" group="brands" />
    <FABGIcon name="github" group="brands" type="square" />
</Example>

```tsx
import { FAIcon, FABGIcon } from 'boot-cell';

<FAIcon name="github" group="brands" />;
<FABGIcon name="github" group="brands" type="square" />;
```

Set `family="duotone" group="solid"` for Duotone icons; `family` also supports
`sharp` and `sharp-duotone`. These non-Free families and styles require
separately supplied Pro assets—BootCell does not bundle them or provide a
fallback.

Use `width="fixed"` or `width="auto"` instead of the removed `fixedWidth`
property. Replace `pull="left"` / `"right"` with `"start"` / `"end"`, and
`animation="pulse"` with `"spin-pulse"`. Icon names are passed through unchanged.
