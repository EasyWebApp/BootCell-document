import { Button, ButtonGroup, ButtonToolbar, ToggleButton } from 'boot-cell';

import { Example } from '../../component/Example';

Use `ButtonGroup` to group related actions. Set `variant` for appearance and
`theme` for color on each button.

<Example>
    <ButtonGroup ariaLabel="Text formatting">
        <Button variant="outline" theme="primary">
            Bold
        </Button>
        <Button variant="outline" theme="primary">
            Italic
        </Button>
        <Button variant="outline" theme="primary">
            Underline
        </Button>
    </ButtonGroup>
</Example>

```tsx
import { Button, ButtonGroup } from 'boot-cell';

<ButtonGroup ariaLabel="Text formatting">
    <Button variant="solid" theme="primary">
        Bold
    </Button>
    <Button variant="solid" theme="primary">
        Italic
    </Button>
</ButtonGroup>;
```

Provide an accessible label with `ariaLabel` or `ariaLabelledBy`. For a
toolbar, use `ButtonToolbar` and give each nested group its own label.

<Example>
    <ButtonToolbar ariaLabel="Editor toolbar">
        <ButtonGroup ariaLabel="Text style">
            <Button variant="solid" theme="secondary">
                Bold
            </Button>
            <Button variant="solid" theme="secondary">
                Italic
            </Button>
        </ButtonGroup>
        <ButtonGroup ariaLabel="Alignment">
            <ToggleButton type="radio" name="alignment" value="left">
                Left
            </ToggleButton>
            <ToggleButton type="radio" name="alignment" value="right">
                Right
            </ToggleButton>
        </ButtonGroup>
    </ButtonToolbar>
</Example>

```tsx
import { Button, ButtonGroup, ButtonToolbar } from 'boot-cell';

<ButtonToolbar ariaLabel="Editor toolbar">
    <ButtonGroup ariaLabel="Actions">
        <Button variant="outline" theme="secondary">
            Undo
        </Button>
        <Button variant="outline" theme="secondary">
            Redo
        </Button>
    </ButtonGroup>
</ButtonToolbar>;
```

The `ToggleButton` input is nested inside its label; selectors must not assume
they are adjacent siblings.
